# cute-mvp

React + Vite로 만든 작은 가상 펫 MVP입니다. 3D 캐릭터를 렌더링하고,
상태를 추적하며 액션으로 아이템을 소모하고 친밀도를 올릴 수 있습니다.

## 주요 기능

- 3D 캐릭터 씬과 히어로 레이아웃
- 상태: 배고픔/피로/지루함(0-100)
- 상태 임계값에 따라 기분 변경
- 액션: 밥/놀기/잠(액션마다 아이템 소모)
- 친밀도 100 도달 시 레벨 상승
- 상점 화면에서 코인으로 아이템 구매

## 동작 방식

- 액션에 따른 상태 변화는 `src/store/mvpStore.ts`에서 정의합니다.
- 기분 단계는 배고픔/피로/지루함 임계값으로 계산합니다.
- 기분에 따라 친밀도 증가폭이 달라집니다(좋음/보통/나쁨 배수).
- 액션마다 특정 아이템(밥/장난감/침대)을 1개 소모합니다.
- 아이템 기본 갯수는 각 20개이며, 상점에서 구매할 수 있습니다.

## 스크립트

- `npm run dev` - 로컬 개발 서버 실행
- `npm run build` - 타입체크 및 빌드
- `npm run preview` - 프로덕션 빌드 미리보기
- `npm run lint` - ESLint 실행

## 프로젝트 구조

- `src/app/App.tsx` - 메인 레이아웃 및 뷰 전환
- `src/store/mvpStore.ts` - Zustand 상태 및 게임 로직
- `src/ui/` - UI 컴포넌트(상태, 기분, 상점, 액션)
- `src/canvas/` - 3D 씬 및 캐릭터 뷰어

## 참고

- 라우터 없이 상점/홈 뷰를 토글합니다.
- 코인과 아이템은 메모리 기반입니다(영속화 미적용).
